# tracer v2 改动与验证记录

日期：2026-10-14。范围：`taco-mutation-light/tracer/`。

## 改动范围

1. **噪声分类和覆盖率**：新增 `adapters/policy.py`；分别报告解释器名称过滤、符号摘要、值缺口、事件截断、检查点缺口及未匹配事件。显式使用/绑定的解释器同名变量保留。
2. **大序列**：新增 `adapters/sequences.py`、`adapters/checkpoints.py` 和 `checkpoint_io.py`；普通行保存首尾及整数局部变量窗口，首次可见/退出检查点分块传输和压缩。变量值、行事件、检查点分别限额，退出检查点不因行事件额度耗尽而直接停用。
3. **机械比较**：保留原始轨迹，修复改动 return 行漏比较、局部缺失导致整对象已知差异被忽略的问题；有限重新对齐，调用实例不明确时保留未匹配，不生成因果依赖边。
4. **模型解释**：一次 DeepSeek 请求产生带证据引用的候选 first_divergence、propagation、trigger_condition，以及 requirement 和逐字 SPEC 引文；机械结果与模型解释分开存储。
5. **字段职责与版本**：observable_consequence 和 oracle target/kind/comparison 来自记录及合同，模型补 requirement。比较和分析工件按版本保存；重比较不保留旧解释作为当前解释。没有行为描述/行为标签自动填表。
6. **工程拆分**：新增 collect/compare/analyze 独立入口、旧工件导入、历史请求保留和资源统计。保留六路采集、两个启动槽、两个比较进程、两个分析线程、容器登记清理和未知请求禁重发。

原变异体生成、官方测试判定、根执行适配器和 LLM 客户端未修改。原有 `runs/` 中的人工编辑文件未修改。新默认诊断输出为 `runs/tracer-v2`。

57 对新材料均能在 100000 字节模型材料预算内构造请求材料；**没有发送这些材料**。新机械观察在 57 对中都有结果渠道差异；这不表示输入均合法、原结果均正确或程序差异已完全解释。

抽查案例：

- `737e1bae`（此前例 B）：原比较 0 条快照差异，新比较 1 条；事件 5 的 return 值差异被检出。
- `afe10df3`（此前例 A）：37 对事件对应，差异序列由 6 条增至 19 条；最早候选移至事件 12 的推导式返回值。
